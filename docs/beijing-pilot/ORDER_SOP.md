# 北京试点 · 派单成交 SOP（第 3–6 周）

## 闭环

1. 用户在群内或 `/beijing/request` 提交需求  
2. 运营在 `/beijing/ops` 看到新需求 → 派给圈层内师傅  
3. 服务完成 → 录入订单：客单、抽佣、售后、来源、城区  
4. 失败单同样录入，并写失败原因  

目标：**至少 20 笔真实成交记账**（含失败单原因完整）。

## 订单必记字段

见 `templates/orders.csv`：来源、品类、客单、抽佣、售后、城区、投诉、状态。

## 每周运营固定动作

- 需求征集（群内 2–3 次，勿刷屏）
- 成交反馈与师傅评价公示（可匿名化）
- 检查群二维码 / 群号页是否仍有效
- 导出或核对本周指标（对接 UNIT_ECONOMICS）

## 抽佣建议

- 默认客单 **15–20%**
- 或品类固定信息费（开锁可试固定额）
- 售后扣减计入 `aftersale_cents`，算入单均毛利

## 来源枚举（勿自创混乱）

`web` | `group` | `seo` | `referral`
