# 北京试点 · 单位经济与去留决策（第 7–12 周）

在 `/beijing/metrics` 查看自动汇总；本文件为判定标准。

## 公式

- **需求→成交率** = 完成订单数 / 有效需求数  
- **客单均价** = Σ amount / 完成单数  
- **单均毛利** = Σ(commission − aftersale) / 完成单数  
- **CAC（含时间）** =（投放费 + 运营时薪×小时）/ 新成交用户数  
- **投诉率** = 有投诉完成单 / 完成单  

健康参考：成交率 ≥ 30%；单均毛利覆盖你的时薪后仍为正；CAC &lt; 该用户 3 个月毛利贡献。

## 继续（北京同城扩量）——须同时满足

1. 连续 4 周有稳定有效需求与成交  
2. 单均毛利为正，且按现有时薪仍划算  
3. 投诉可控，师傅愿意留  
4. 至少一种可重复获客（SEO / 老带新 / 物业转介等）

## 停损——出现任一即触发

1. 90 天真实成交极少，靠「以后广告/省代」叙事续命  
2. 靠卖广告维持群，用户退群/举报  
3. 频繁封码封群且无企微/表单留资  
4. 售后打穿利润  

达标后只做北京同圈层加密；不省代、不跨城。
