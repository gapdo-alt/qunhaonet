# 北京试点 · 师傅建档与上岗

## 目标（0–2 周）

完成 **至少 10 名** 本地师傅建档，服务半径落在试点圈层内。

## 品类（先只开这三类）

- 开锁（需提示资质与实名）
- 水管小修
- 电路小修（非大型改造）

## 建档字段（与运营台 / CSV 一致）

| 字段 | 必填 | 说明 |
|---|---|---|
| 姓名 | 是 | |
| 电话 | 是 | 唯一联系 |
| 品类 | 是 | 可多选，逗号分隔 |
| 服务城区 | 是 | 如：朝阳,通州 |
| 实名核验 | 是 | 是/否；开锁建议必须「是」 |
| 备注 | 否 | 报价习惯、可接紧急单等 |
| 状态 | 是 | active / paused / left |

模板：`docs/beijing-pilot/templates/craftsmen.csv`

## 面试要点（15 分钟电话即可）

1. 能否在约定圈层 **60–90 分钟内响应**（紧急开锁另约）
2. 公开报价口径是否接受平台公示参考价
3. 是否接受平台抽佣 **15–20%** 或固定信息费
4. 纠纷是否配合平台售后（返工/部分退佣）

## 上岗

1. 写入运营台「师傅」或导入 CSV 后录入 `/beijing/ops`
2. 状态为 `active` 方可派单
3. 连续拒单或投诉升高 → `paused`

## 禁止

- 未建档进群揽活
- 超服务半径硬接导致迟到翻车
- 把「最便宜」当唯一卖点
