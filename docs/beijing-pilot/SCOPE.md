# 北京单城试点 · 范围锁定（书面确认）

> 状态：已拍板  
> 城市：北京（唯一）  
> 产品壳：qunhao.net（入口 + 信任 + SEO，非终局产品）

## 做

| 线 | 内容 | 角色 |
|---|---|---|
| A 主线 | 小区社群 → 开锁 / 水管 / 电路小修撮合 | 验证单位经济 |
| B 辅线 | 北京主机游戏群 | 养人与导流，不扛利润 |
| 站 | `/beijing` 目录、报修表单、SEO 页、运营台账 | 获客与记账 |

## 不做（试点期书面禁止）

- 省份经营权 / 加盟招商
- 美妆、培训广告作为主收入
- 游戏卡带租赁作为主业
- 多城并行或「先全国再验证」
- 飞书作为主战场
- 复杂 App / 重派单系统（先用站内表单 + 运营台）

## 地理策略

先选 **一个可履约的城区圈层**（同一行政区或相邻商圈），禁止「全北京接单」。

默认试点圈层文案：**朝阳 / 通州相邻带**（可在运营中改，但同时只保留一个圈层）。

## 继续 / 停损（摘要）

继续需同时：连续 4 周有稳定需求与成交、单均毛利为正、投诉可控、至少一种可重复获客。

停损触发任一：90 天几乎无真实成交、靠卖广告维持群、频繁封群且无留资沉淀、售后打穿利润。

## 共识一句话

验证的是「本地社群能否稳定产生可抽佣的服务交易」，不是「网站好不好看」。
