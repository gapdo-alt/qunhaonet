## 主小区群（本地服务）

**群定位**：本小区 / 本圈层邻居互助；平台「群号」提供报修入口与师傅履约。

1. 禁止乱发广告、外链引流、医美培训推销；违规移出。
2. 有开锁、水管、电路等需求：优先走群号报修页（群公告链接），便于派单与售后。
3. 私下成交自负；经平台派单的订单享售后跟进。
4. 师傅仅限已建档、服务半径内接单；禁止未审核人员在群内揽活。
5. 二维码失效：联系群主或打开群号页「联系群主」。
6. 敏感信息（门牌全号、证件）勿公屏；私聊或表单提交。

**需求怎么提（简版）**  
品类 + 大概位置（小区/街道即可）+ 联系方式 + 是否紧急。

**师傅怎么进**  
私聊群主提交：姓名、电话、品类、服务城区、资质说明 → 建档后才可接单。

## 主机游戏群（辅线）

**群定位**：北京主机玩家交流（二手信息、组队、活动）。不承担主利润。

1. 禁止刷广告、卡带租赁商家群发；置顶/活动需群主同意。
2. 二手交易自行验货，群主不担保。
3. 可轻量测试：活动报名、信息置顶小额费用（需记账，不冲主线指标）。
4. 导流报修/本地服务时，用「自愿」口吻，勿刷屏。
